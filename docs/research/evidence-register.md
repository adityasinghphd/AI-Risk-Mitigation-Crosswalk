# Evidence register

This register connects the research summary to dated project artifacts. The [JSON summary](evidence/project-evidence.json) records original artifact paths, SHA-256 hashes, measured fields, and selected example records. Paths identify artifacts in the research workspace; this repository includes selected evidence and examples. Hashes bind the summary to those artifacts but do not independently establish semantic correctness.

The taxonomy review interfaces described in the project introduction exist in the research workspace. Their publication scope has not been decided; the tools and full category definitions are not included in this evidence bundle. The seven original pilot example records remain in the JSON for continuity and are separate from its current_explorer summary.

A hash identifies the retained source used for a summary. It is not a substitute for access to the full source or independent reproduction. The public extract exposes selected evidence and aggregate findings; it does not claim that every internal artifact is publicly downloadable.
